# Tech stack

- `backend/`: FastAPI and SQLite. Every API operation has an `operation_id`, a one-line docstring and no optional inputs. Paying a claim is a separate operation that takes the amount. The policy wording and the claims manual are split into their headed sections at load time, read by section rather than handed over whole. A run's to-do list (one row per claim it works, with its status and attempts) lives in SQLite alongside claim status. Routes in `main.py` are thin; claim and run logic is in `claims.py` and `runs.py`, and `NotFound` and `Conflict` errors become 404 and 409 in one place. Money is `Decimal` dollars in Python, a two-decimal string on the wire and whole cents in SQLite (`backend/money.py`). A claim is decided once and paid once, enforced by a conditional `UPDATE`.
- `agent/`: two LangChain `create_agent`s on OpenRouter, both reaching claims, documents and instructions only through the backend's API. `api.py` is the only module that makes HTTP calls. `harness.py` builds the model and runs an agent (generic, no claims). `tools.py` holds every tool, each reading its state from `ToolRuntime[ClaimContext]` or `ToolRuntime[RunContext]` (LangChain's `context_schema`). `agents.py` has the two entry points: `decide_claim(claim_id)` decides one claim from a clean start, and `run_queue(cap=None)` starts a run over the waiting claims (capped if asked) and has the orchestrator work through the to-do list, handing each claim to a fresh `decide_claim` subagent. `work.py` is the retry policy, deterministic Python rather than left to the model: a failed claim goes back in the queue and is tried once more, then left for a handler, and a run can't finish early. `cli.py` starts either from the command line. The model has a request timeout. The default model is `deepseek/deepseek-v4.1-flash` at low reasoning effort, or the model in the environment variable `MODEL_NAME` if set, such as `openrouter/free`.
- `dashboard/`: React, Vite and TypeScript.
- `e2e/`: Playwright tests.
- `data/`: the business data the backend starts from. The agent never sees `data/evals/`, which holds the answer key.

Python 3.12 with uv, all in the root `pyproject.toml`. Node 26. The OpenRouter key is `OPENROUTER_API_KEY` in `.env`.
