# Tech stack

- `backend/`: FastAPI and SQLite. Every API operation has an `operation_id`, a one-line docstring and no optional inputs. It stores requests with their attempts, steps, recommendation and review, and runs with their to-do lists and summaries, and it serves the policies section by section. `npm run seed` rebuilds the database. The product recommends support outcomes; it does not execute cancellations, returns, or refunds.
- `agent/`: LangChain's `create_agent` on OpenRouter, in two parts. The queue agent (`agent/queue.py`, `run_queue(run_id, cap)`) plans a run as a to-do list and hands each request to the request agent through its `work_request` tool. The request agent (`agent/main.py`, `run_request(request_id, thread_id)`, wrapped by `work_request(request_id)`) works one request on a fresh thread per attempt and reports back in one line. LangChain middleware does the harness work: `ModelRetryMiddleware` and `ToolRetryMiddleware` retry passing errors, and an `after_agent` hook sends the queue agent back if it misses a waiting request within its cap. Both reach request, order, run and policy data only through the backend's API. `uv run -m agent REQ-7001` works one request and `uv run -m agent --cap 5` starts a capped run. The default model is `deepseek/deepseek-v4.1-flash` with low reasoning effort, or the model in the environment variable `MODEL_NAME` if set, such as `openrouter/free`, with no reasoning effort set.
- `dashboard/`: React, Vite and TypeScript.
- `e2e/`: Playwright tests.
- `data/`: Shoppie's synthetic customer, order, and support request data. The agent never sees `data/evals/`, which holds reference decisions for evaluation.

Python 3.12 with uv, all in the root `pyproject.toml`. Node.js 24.15.0, pinned in `.nvmrc`. The OpenRouter key is `OPENROUTER_API_KEY` in `.env`.
